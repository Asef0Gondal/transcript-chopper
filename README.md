# ✂️ Transcript Chopper

An elegant, premium desktop utility designed for AI content creators and writers. Automatically splits massive transcript documents or raw text logs into perfectly sized 10,000-word canvas files, ensuring it never cuts mid-sentence for seamless ingestion into LLMs like Gemini or ChatGPT.

---

## ✨ Features
- **⚡ Intelligent Boundaries:** Never breaks text mid-sentence—waits for standard punctuations (periods, questions, exclamations).
- **📂 One-Click Finder Sync:** Automatically creates a dedicated sub-folder and pops open a Finder window upon completion.
- **🖥 Interactive GUI:** Beautiful lightweight Tkinter-based desktop interface.
